# «Вулик» — конвеєр анімаційного серіалу для TikTok

Україномовний анімаційний серіал про те, як двоє друзів відкривають у Львові бар, де продають тільки медовуху.
Кожна серія — вертикальне відео 1080×1920 тривалістю до 2:30: лічильник грошей, лічильник днів, караоке-субтитри,
звуки на кожну появу елемента і питання до глядачів наприкінці. Наступна серія пишеться з урахуванням коментарів.

Весь проєкт зроблено методом вайбкодингу: я ставлю задачі звичайною мовою, а код, сценарії й анімацію пише
ШІ-агент (Claude Code). Я відповідаю за ідею, рішення, перевірку і публікацію.

**Готові відео:** [`parts/part1/part1.mp4`](parts/part1/part1.mp4) … [`parts/part5/part5.mp4`](parts/part5/part5.mp4),
підсумки [`parts/recap1/recap1.mp4`](parts/recap1/recap1.mp4).

## Як це працює

```
сценарій (lines.py) ─► озвучка (Lumean / ElevenLabs, таймінги кожного слова)
        │                        │
        ▼                        ▼
 перевірка канону ──► сцени (scene.html, SVG + JS) ──► рендер кадрів (headless Chromium)
 (check_canon.py)                                       │
                                                        ▼
                         звуки + голос + відео (ffmpeg) ─► partN.mp4 ─► Telegram-бот (tg_post.py)
```

- **Сценарій як дані.** `lines.py` у кожній серії: текст субтитрів, текст для озвучки з наголосами (U+0301),
  ключ сцени і рухи грошей. Баланс на екрані рахується з цих даних, тож цифри у відео завжди сходяться.
- **Канон.** `canon.md` — єдине джерело фактів (гроші, люди, дні). `check_canon.py` перевіряє, що кожна серія
  починається з тієї суми, якою закінчилась попередня.
- **Озвучка.** `voice_lumean.py` озвучує весь текст одним замовленням (рівна інтонація), ріже його на фрази за
  таймінгами слів; репліки персонажів іншими голосами. Числа в субтитрах («70 000») зіставляються з вимовленими
  словами («сімдесят тисяч») функцією `map_words()`.
- **Анімація.** `scene.html` малює все в SVG: персонажі, реквізит, плашки; кожен елемент з'являється точно на
  потрібному слові. `render.py` знімає кадри через Playwright, `build.py` додає голос і звукові ефекти
  (синтезовані `make_sfx.py`) і збирає mp4.
- **Публікація.** `tg_post.py` надсилає готову серію і тексти постів у Telegram через власного бота. У канал —
  тільки після мого підтвердження. TikTok викладаю вручну.
- **Переглядач.** `app.py` + `studio.html` — локальна сторінка для перегляду серій, сценарію і балансу.

## Стек
Python, JavaScript/SVG, Playwright (Chromium), ffmpeg, Lumean API (голоси ElevenLabs), Telegram Bot API.

## Запуск (macOS)
```bash
brew install ffmpeg
python3 -m venv .venv && .venv/bin/pip install playwright && .venv/bin/playwright install chromium
cp .env.example .env   # вписати свої ключі
python3 voice_lumean.py parts/part1          # озвучка
.venv/bin/python build.py parts/part1        # рендер -> parts/part1/part1.mp4
python3 check_canon.py                       # перевірка грошей між серіями
```
Кадри для перевірки перед повним рендером (з папки серії):
`../../.venv/bin/python ../../render.py timing.json x.mp4 5.0,12.3`.

## Структура
- `parts/<серія>/` — `lines.py`, `scene.html`, таймінги, тексти постів, готове відео.
- `canon.md`, `characters.md` — факти світу і персонажі.
- `CLAUDE.md` — інструкції для ШІ-агента: правила проєкту, рішення автора, процес.

Аудіо і проміжні файли в репозиторій не входять, вони генеруються заново. Ключі API лежать тільки в `.env`
(у `.gitignore`). Шрифт Inter — SIL OFL.
